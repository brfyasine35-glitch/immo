2) Data handled in the app

The app allows users to enter and manage:

  • Property information: name, type, city, rent, occupancy status.
  • Client information: name, phone number, contract start date, assigned property.
  • Financial inputs: values used for forecast and loan calculations.
Collected Name, phone number, contract date, assigned property, property and finance inputs.
Shared Name, assigned property, contract start date only when user shares report text.

3) How data is used

  • Display and manage portfolio and client records.
  • Calculate financial forecasts and loan estimates.
  • Generate report text inside the app.
  • Share report text only when the user explicitly taps Share.

4) Data collection and sharing

  • The app does not automatically transmit personal data to the developer.
  • The app does not include advertising, analytics, or tracking SDKs.
  • Data leaves the app only through user-initiated Android sharing.
  • Shared report text may include client name, assigned property, and contract start date.
  • Client phone numbers are entered and used in-app but are not included in shared report text by default.

5) Storage, retention, and deletion

  • Data is stored in app memory for the active app session only.
  • No account system is required.
  • No server-side storage or cloud synchronization is used by this app.
  • Session data is deleted automatically when the app session ends (under 90 days).

Data deletion request in-app is not required (no persistent account data).

6) Permissions

The app does not request sensitive runtime permissions such as:

  • Camera
  • Microphone
  • Location
  • Contacts
  • Phone/SMS/Call log

7) Security

  • Data processing is local on the user device by default.
  • No automatic backend transfer is performed by the app.
  • If the user exports/shares data, protection then depends on the selected third-party app/service and channel.

8) Children’s privacy

This app is intended for business and real-estate operations and is not directed to children.
