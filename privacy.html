Data handled in the app

The app allows users to enter and manage:

  • Property information: name, type, city, rent, occupancy status.
  • Client information: name, phone number, contract start date, assigned property.
  • Financial inputs: values used for forecast and loan calculations.

3

How data is used

Data entered by the user is used to:

  • Display and manage portfolio and client records.
  • Calculate financial forecasts and loan estimates.
  • Generate report text inside the app.
  • Share report text only when the user explicitly taps Share and selects a destination app.

4

Data collection and sharing

  • The app does not automatically collect personal data for transmission to the developer.
  • The app does not include advertising, analytics, or tracking SDKs.
  • Data leaves the app only through user-initiated actions (for example, sharing report text via Android share sheet).

5

Storage and retention

  • Data is stored in app memory for the active app session.
  • No account system is required.
  • No server-side storage or cloud synchronization is provided by this app.

6

Permissions

The app does not request sensitive runtime permissions such as:

  • Camera
  • Microphone
  • Location
  • Contacts

7

Security

  • The app is designed to keep processing local on the device.
  • When a user chooses to export or share data, protection of that data depends on the selected third-party app/service.

8

Children's privacy

This app is intended for business/real-estate operations use and is not directed to children.

9

Changes to this policy

We may update this policy when app features or data practices change. The latest version is shown in-app and in this document.
